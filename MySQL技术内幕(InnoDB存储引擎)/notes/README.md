## 建议阅读顺序

1. **第 5 → 6 → 7 章**（索引 / 锁 / 事务）：原理密度最高，先建立正确模型。  
2. **第 2 → 3 → 4 章**：用 8.0.34 对照替换 Insert Buffer→Change Buffer、文件布局、行格式与分区等过时写法。  
3. **第 8 章**：现代备份（Clone / XtraBackup 8.0 / MEB）与 replica / GTID / Group Replication。  
4. **第 1、9、10 章**：选型历史、硬件叙事、5.1 调路径——当启发与 WHY，实操以 8.0.34 文档与源码为准。

也可按书序 01→10 读；每读完一章，翻一次过时对照，避免把 5.6 参数背进生产。
