### 0.3 安全与规则
1. 测量一律先断电、拔电池排线再动手。**鼓包电池不要再装回使用**。
2. 二极管档读数没有"标准答案"，必须与同型号好板或同一块板上相同功能的另一路对比。
3. 先测量后动烙铁，不要一上来就换件。

### 1.2 EC 的 SMBus 拓扑（页 3）
EC（UE1）通过三组 SMBus 管理外设：
- **SMB0**（EC_SMB_CK0/DA0）：USB-C PD（U4）、AG 控制器（U22）。
- **SMB1**（EC_SMB_CK1/DA1，+3VALW_R）：**电池 JBATT1（地址 0x16）、充电芯片 PU201（0001 0010b）**。
- **SMB2**（EC_SMB_CK2/DA2，+3VS）：GPU（0x9E）、温度传感器 F75303M/NCT7718W。

**意义**：EC 要通过 SMBus 与 PU201 通信才能正常管理充电；如果 EC 没起来，充电灯、电池充电都不会工作。

### 2.3 开机流程（根据网络名归纳，因果顺序以图纸分页为准）

```
① 适配器 20V → JDCIN1 → PF101 → ACFET(PQ201/PQ202) → V20B+
        │   适配器的 ID 针 → ADAPTER_ID → EC（识别功率）
② V20B+ → PU601 内部 LDO → +3VLP/+3VL（约 3.3V）→ EC UE1 上电（待机）
        │   PU201(BQ24780S) 通过 ACOK 告诉 EC "有适配器"
③ EC 运行 → 输出 EC_ON → PU601 的 EN1/EN2 → +3VALW、+5VALW 建立 → ALW_PWRGD
        │   同时 EC_ON 也使能 VCCIO（PU901）等
④ 你按电源键（ON/OFFBTN#）→ EC → PBTN_OUT# → PCH（DNBSWON#）
⑤ PCH 发出 SLP_S3/S4 → EC 输出 SUSP#、SYSON、PCH_PWR_EN
        ├─ SUSP# → +3VS/+5VS、VDDQ、VCCIO、VCCSTG
        ├─ SYSON → +2.5V、内存 VDDQ（SYSON_VDDQ）
        └─ PCH_PWR_EN → +1.8VS_AON、+3VALW_PCH
⑥ EC 输出 CPUCORE_ON → PU2901 → CPU 核心电压 → VR_RDY/CPU_PWRGD 回 EC
⑦ GPU 电源：FBVDDQ_PWR_EN、NVVDD_EN、PXS_PWREN（页 54）依次起来
⑧ PCH_PWROK / SYS_PWROK → PLT_RST# 释放 → CPU 读 SPI BIOS → 点亮屏幕
```

### 2.4 用这张图读你的症状

| 你的症状 | 说明走到了哪一步 |
|---|---|
| 充电灯、电源灯都不亮 | 卡在 ①~②：V20B+ 没起来 / PU601 没输出 3VL / EC 没起来 |
| 灯亮但按键无反应 | ③~④：EC 活着，查 EC_ON 是否发出、+3VALW/+5VALW 是否正常、电源键信号 |
| 风扇一转就停 | ⑤~⑥：某路电压对地短路，保护触发 |
| 有风扇没画面 | ⑥~⑧：BIOS、内存、CPU、显示链路 |

**你的情况（所有灯都不亮）属于第一行。**

## 6. 排查流程（用真实位号）

### 6.1 总流程

| 优先级 | 步骤 | 位号/测点 | 判断 |
|---|---|---|---|
| 1 | 外观检查：JDCIN1、PF101、PQ201/PQ202、PU201、PU601、PU3001~PU3004、PU7502~PU7504 有无烧黑、炸裂、鼓包 | 3.1、3.2、3.4、3.5 | 看到异常元件就是重点 |
| 2 | 适配器输出电压 | 适配器 | 约 20V；有条件换一个适配器对比 |
| 3 | M-beep 测 **PF101** 两端 | PF101 | 不响 = 保险丝熔断，**先找短路原因再换** |
| 4 | M-diode 测 **VIN（PF101 后）对地** | PF101 后端、PC201 等 | 0 = 入口后短路 |
| 5 | M-diode 测 **V20B+ 对地**（PR201 后端或任一大电容） | PR201 后端 | **接近 0 = 母线被短路** |
| 6 | M-psu：20V、限流 0.5A 接 DC 口，观察电流 | JDCIN1 | 见 6.2 |
| 7 | 上电测 V20B+ | PR201 后端 | 约 20V；无 = ACFET/PU201 |
| 8 | 上电测 **+3VL**（PU601 的 LDO 输出） | PU601 附近 | 3.3V；无 = PU601 或前级 |
| 9 | 测 +5VLP、+3VALW、+5VALW | PU601 输出电容 | 缺哪个查哪个 |
| 10 | 查 EC：UE1 供电脚 | UE1 | 3.3V |
| 11 | 按电源键后依次测 EC_ON、SUSP#、SYSON、PCH_PWR_EN、CPUCORE_ON | 对应网络 | 找第一个没起来的 |
| 12 | 逐路 M-diode 找短路，用 M-psu 倒灌找发热元件 | 各 DrMOS 的 VIN | 发热元件即故障点 |
| 13 | 以上都正常，才怀疑 BIOS Flash、EC 固件、BGA 芯片 | 页 20、50 | 属高阶维修 |

### 6.2 可调电源电流判读

| 电流读数（20V、限流 0.5A） | 含义 | 方向 |
|---|---|---|
| 0.000A 不变 | 入口开路 | PF101、PQ201/PQ202、JDCIN1 |
| 冲到限流、电压被拉低 | 短路 | 见 6.3 |
| 0.01~0.05A 稳定 | 待机电路在工作，但 EC 没起来 | EC 供电、复位、固件 |
| 按键后跳变 0.3~1A 又回落 | 开机后某路保护 | 找对应电压对地短路 |
| 稳定在 0.5A 以上 | 可能已启动 | 接屏幕看 |

### 6.3 找短路的重点嫌疑（你的"游戏加载瞬间死机"）

CPU 和 GPU 核心都是多相 Buck，每相的功率级都直接挂在 **V20B+** 上，所以任何一颗击穿，都会把整条母线拉到地：

| 嫌疑优先级 | 元件 | 位号 | 测法 |
|---|---|---|---|
| 1 | CPU 核心功率级 | **PU3001~PU3004** | M-diode 测各自 VIN 脚对地，四颗互相对比 |
| 2 | GPU 核心功率级 | **PU7502~PU7504** | 同上，三颗互相对比 |
| 3 | 核显功率级 | PU3102 | 同上 |
| 4 | V20B+ 上的 MLCC 电容 | 各 DrMOS 旁 | M-diode，用倒灌+酒精找发热点 |
| 5 | ACFET / 充电 MOS | PQ201、PQ202、PQ205、PQ206 | M-diode |
| 6 | PU601 的 Buck 通道 | PQ601~PQ604 | M-diode |

**对比法**：同一类的几颗功率级（如 PU3001~PU3004）读数应基本一致，**明显偏低的那颗就是嫌疑**。

### 9.2 怎么用图纸 PDF 和点位图配合
1. 在 PDF 里搜位号，如 **PF101**、**PU601**，可以直接跳到它所在页。
2. 在 Tebo-ictview 里搜同一位号，就能看到它在板子上的物理位置。
3. 在点位图里点中一个网络（如 V20B+），所有连在这条线上的焊点会高亮，用来找短路时特别有用。
4. 网络名读法：`+3VALW` 末尾 ALW=Always（待机常有）；`+3VS` 末尾 S=Switched（开机后才有）；`#` 结尾=低电平有效；`_EN`=使能；`_PG`/`PWRGD`=电源好信号。

## 10. 本手册仍无法确认的事项（勘误与待办）
